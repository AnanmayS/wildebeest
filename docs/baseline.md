# Phase 1 baseline: single-process SpeciesNet

Generated by `scripts/baseline.py` on 2026-09-25. Evaluated every image in `data/sample/labels.csv`.

Pipeline (identical to the distributed workers): MegaDetector v5a on every image; if any animal box has conf >= 0.2, the SpeciesNet v4.0.3a classifier runs on the top animal crop and the package's ensemble + geofence (country `TZA`) picks the label. Model `kaggle:google/speciesnet/pyTorch/v4.0.3a/1`, speciesnet 5.0.5, PyTorch on CPU (Apple M2 host, one process, default torch threads). Predictions: `benchmarks/baseline_predictions.csv`.

## How labels are compared

Ground truth is the Snapshot Serengeti sequence label (`common_name` in `data/sample/labels.csv`:
`gazellethomsons`/`gazellegrants` → gazelle, `lionfemale`/`lionmale` → lion, `hyenaspotted`/`hyenastriped` → hyena).
SpeciesNet predictions go through `wildebeest_worker.labels.common_name()`, which maps the taxonomy
string by genus/family: any zebra → zebra, *Connochaetes* → wildebeest, *Panthera leo* → lion,
Elephantidae → elephant, Giraffidae → giraffe, *Eudorcas*/*Nanger*/*Gazella* → gazelle, *Syncerus* → buffalo,
*Crocuta*/*Hyaena*/*Parahyaena* (or the Hyaenidae roll-up) → hyena, *Phacochoerus* → warthog, *Aepyceros* → impala.
Anything else keeps SpeciesNet's own common name (e.g. `bovidae family`, `equus`, `animal`, `blank`) and counts as wrong.

Caveat: Snapshot Serengeti labels are per *sequence* (burst of ~3 frames) and we sampled one random
frame per sequence, so some "animal" ground-truth frames genuinely show no animal. That caps the
achievable animal recall below 100% and makes this a conservative estimate.
## Run notes

- Host: Apple M2 (8 cores), macOS, native (not Docker), PyTorch 2.14 CPU with 7 intra-op threads.
  SpeciesNet's detector would pick Apple's MPS GPU by default; `SpeciesNetDetectorModel` moves it back
  to CPU so the baseline matches the CPU-only worker containers. Model load took ~3–4 s (weights in the
  local kagglehub cache).
- The run shared the machine with a `docker compose build` and other work for part of the time, so the
  mean (1.37 s/image, 0.73 img/s) is slightly pessimistic; the median image took 1.27 s (≈0.79 img/s)
  and p90 1.80 s.
- 140 ground-truth-empty images had an animal box ≥ 0.2 and went to stage 2. The stage 2 ensemble
  called 62 of them `blank` and none of the 582 real animal images `blank`. Treating an ensemble
  `blank` as empty raises empty-vs-animal accuracy from 92.1% to 95.2% (precision 80.6% → 88.2%)
  with no recall loss. The coordinator currently marks every stage 2 image `animal` (CONTRACTS.md);
  mapping `commonName == "blank"` to `empty` is a one-line coordinator change worth making.
